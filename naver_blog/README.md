# 네이버 블로그 글쓰기 자동화

`keywords.csv`의 키워드와 메모로 Claude가 글(제목, 본문, 해시태그)을 쓰고,
Playwright가 네이버 스마트에디터에 입력한 뒤 **임시저장**합니다. 발행 버튼은 직접 누르는 게 기본입니다.

> ⚠ 네이버 운영정책은 자동화 프로그램으로 글을 쓰는 것을 제한합니다. `auto_publish = true`로
> 완전 자동 발행을 켜면 검색 누락, 저품질 판정, 글쓰기 제한, 계정 정지 위험이 있습니다. 본 계정이 아닌
> 계정으로 먼저 시험하고, 하루 1~2개 이하로 쓰세요.

## 코딩을 모르면 (Windows)

1. [python.org](https://www.python.org/downloads/)에서 Python을 설치합니다. 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. 이 폴더에 `api_key.txt`를 만들고, Claude API 키를 붙여넣은 뒤 저장합니다.
3. `config.toml`을 메모장으로 열어 `blog_id`를 내 블로그 아이디로 바꿉니다.
   (선택) 무료 사진을 자동으로 넣으려면 [pixabay.com](https://pixabay.com/api/docs/)에 가입해 API 키를 받아
   이 폴더의 `pixabay_key.txt`에 붙여넣습니다. 없으면 무료 사진만 빠지고 썸네일/요약 카드는 그대로 만들어집니다.
4. 아래 파일을 순서대로 더블클릭합니다.
   - `1_install.bat`: 필요한 프로그램 설치 (처음 한 번만)
   - `2_login.bat`: 브라우저가 뜨면 네이버에 로그인하고, 검은 창에서 Enter
   - `2-5_make_photo_folders.bat`: 키워드마다 `photos` 폴더 안에 사진 폴더를 만듦. 여기에 직접 찍은 사진을 넣으면
     Claude가 사진을 보고 글을 쓰고, 어울리는 소제목 아래에 사진을 배치합니다
   - `3_test_write_only.bat`: 글만 만들어서 `output` 폴더에 미리보기(.html)로 저장 (네이버에는 안 올림). 더블클릭하면 브라우저로 열림
   - `4_run_save_draft.bat`: 네이버에 입력하고 임시저장
   - `6_keyword_finder.bat`: 큰 주제를 넣으면 요즘 소식을 검색해 롱테일 키워드 후보 20개와 제목 예시를 뽑고,
     네이버 API 키가 있으면 월 검색량·블로그 문서 수로 S/A/B/C 등급을 매깁니다. 고른 키워드는 `keywords.csv`에 추가됩니다.
   - `7_season_keywords.bat`: 이번 달과 다음 달에 검색이 몰리는 시즌 키워드(세금 신고·납부, 지원금 지급일, 명절 등)를
     올해 일정으로 확인해 추천합니다. `6_keyword_finder.bat`에서 주제 없이 엔터를 눌러도 같습니다.
     키는 처음 실행하면 생기는 `naver_keys.txt`에 적습니다 (네이버클라우드 NAVER API HUB 블로그 검색, 네이버 검색광고 API).
   - `9_voice_test.bat`: 클립 목소리 후보들을 같은 문장으로 녹음해 `output/목소리_샘플/`에 저장합니다. 들어 보고 `config.toml` `[clip]`의 `voice`에 적으세요.
   - `8_make_clip.bat`: 쓴 글로 네이버 클립용 세로 영상(30~40초 mp4)을 만듭니다. 블로그 통계의 조회수 순위를 읽어
     인기 글을 목록 위에 보여 주고, 번호를 고르면 `output/날짜_키워드_클립/`에 `clip.mp4`, `설명_해시태그.txt`,
     `자막.srt`, `대본.txt`가 생깁니다. 목소리는 마이크로소프트 Edge 무료 한국어 음성(인터넷 필요)이고, 안 되면 윈도우 기본 음성, 그것도 없으면 자막만 있는 영상이 됩니다. 목소리·빠르기는 `config.toml`의 `[clip]`에서 바꿉니다.
     업로드는 직접 합니다. 이 기능이 생긴 뒤에 쓴 글만 클립으로 만들 수 있습니다 (글마다 `output`에 .json 저장).
     `config.toml`에 `[clip]` `auto = true`를 넣으면 글을 쓸 때마다 클립도 같이 만듭니다.
     배경은 장면마다 Pixabay 무료 동영상(움직이는 배경)을 찾아 쓰고, 없으면 글의 사진을 천천히 확대합니다.
     첫 장면은 밝은 배경에 핵심 숫자를 크게 넣습니다. `music` 폴더에 무료 음악 파일을 넣으면 작게 깔립니다.

## 설치

```bash
cd naver_blog
pip install -r requirements.txt
playwright install chromium
export ANTHROPIC_API_KEY=sk-ant-...     # Claude API 키
```

## 사용 순서

1. `config.toml`에서 `blog_id`를 내 블로그 아이디로 바꿉니다.
2. 로그인 세션을 저장합니다. 브라우저가 뜨면 직접 로그인하세요. 아이디와 비밀번호는 코드에 저장하지 않습니다.
   ```bash
   python login.py
   ```
3. `keywords.csv`에 키워드를 추가합니다. `memo`에 **직접 겪은 내용**을 적을수록 글이 좋아지고 저품질 위험도 줄어듭니다.
   Claude는 메모에 없는 경험을 지어내지 않도록 지시되어 있습니다. `status`는 비워 두세요.
4. 먼저 원고만 뽑아서 확인합니다. 네이버에는 올리지 않고 `output/`에 저장만 합니다.
   ```bash
   python main.py --dry-run
   ```
5. 실제로 실행합니다. 에디터에 입력하고 임시저장까지 합니다.
   ```bash
   python main.py --no-wait
   ```
   네이버 블로그의 "임시저장 글"에서 내용을 확인하고, 조금 손본 뒤 직접 발행하세요.

처리한 키워드는 `keywords.csv`의 `status`에 `draft 날짜`가 기록되고, 다음 실행 때 건너뜁니다.

## 매일 자동 실행 (cron)

```cron
# 매일 오전 9시에 실행. 실제 시작은 start_jitter_minutes만큼 랜덤으로 늦어집니다.
0 9 * * * cd /경로/naver_blog && /usr/bin/python3 main.py >> run.log 2>&1
```

`headless = true`로 바꿔야 화면 없는 서버에서도 돌아갑니다.

## 설정 (`config.toml`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `auto_publish` | `false` | `true`면 검토 없이 바로 발행합니다 (위험) |
| `max_posts_per_day` | 1 | 하루에 처리할 최대 글 수 (`state.json`에 기록) |
| `start_jitter_minutes` | 0~90 | 실행을 시작하기 전 랜덤 대기 |
| `between_posts_minutes` | 40~120 | 글과 글 사이 랜덤 대기 |
| `model` | `claude-opus-5` | 글을 생성할 Claude 모델 |

## 문제 해결

- **"로그인 세션이 만료되었습니다"**: `python login.py`를 다시 실행하세요.
- **에디터 입력이나 저장이 실패함**: `output/error_*.png` 스크린샷을 확인하세요. 네이버가 에디터를 개편하면
  `publish.py` 맨 위의 `SELECTORS`만 고치면 됩니다.

## 카테고리 자동 지정

`keywords.csv`의 넷째 칸에 카테고리 이름을 적으면 그 카테고리로 임시저장합니다.

```
keyword,memo,status,category
연말정산 미리보기,"작년에 미리보기로 확인해 봄",,경제·재테크
박나래 매니저 소송,,,연예·이슈 기록
```

- 이름은 블로그 카테고리 이름과 같게 적습니다 (띄어쓰기·가운뎃점 차이, 글 개수 표시는 무시).
- 카테고리 목록은 처음 한 번 읽어 `categories.json`에 저장합니다. 카테고리를 새로 만들었으면 이 파일을 지우세요.
- 넷째 칸이 비어 있으면 `config.toml` `[naver]`의 `category = "..."`, 그것도 없으면 블로그 기본 카테고리로 저장됩니다.

## 카드뉴스 (인스타그램)

글을 쓸 때마다 `output/날짜_키워드_카드뉴스/`에 4:5 세로 카드 7~9장(표지 → 소제목별 → 자주 묻는 질문 → 한눈에 정리 → 블로그 안내)과
인스타 본문에 붙여넣을 `캡션.txt`가 생깁니다. Claude 비용은 들지 않습니다. 끄려면 `config.toml` `[images]`에 `card_news = false`.

## 소제목 서식

소제목 상자 안 글자에 편집기의 '소제목' 문단 서식(본문 ▾ 메뉴)을 적용해, 검색엔진이 소제목 구조를 알아보기 쉽게 합니다.
실행 창의 `소제목 서식(검색엔진용): ○/○개`로 결과를 볼 수 있고, 안 되면 `output/editor_heading.txt`에 이유가 남습니다.
끄려면 `config.toml` `[style]`에 `heading_format = false`.

## 지금 뜨는 키워드 (11_trending_keywords.bat)

네이버 크리에이터 어드바이저의 '주제별 인기 유입 검색어'를 읽어, 내 블로그 주제(경제·생활·연예 등)에 맞는 것만
검색량·경쟁도로 S/A/B/C 등급을 매겨 보여 줍니다. 번호를 고르면 `keywords.csv`에 카테고리와 함께 들어갑니다.
로그인은 `2_login.bat`으로 저장한 세션을 씁니다. 못 읽으면 `output/trend_debug.png`, `trend_debug.txt`를 캡처해 보내 주세요.
주제 → 카테고리 연결을 바꾸려면 `config.toml`에 `[trending.map]` 칸을 만들고 `"여행" = "리뷰,후기"`처럼 적습니다.


## 평생 키워드 (12_evergreen_keywords.bat)
유행이 지나도 매달 꾸준히 검색되는 키워드를 찾습니다. 한 번 써 두면 몇 년 동안 유입이 들어오는 글감입니다.

- 엔터만 누르면 광고 단가가 높은 주제(세금·적금·지원금·보험·건강·자격증·생활)에서 씨앗 키워드를 골라 연관 키워드를 모읍니다.
- 지난 2년 검색 흐름을 보고 이렇게 나눕니다.
  - **[평생]** 1년 내내 고르게 검색됨 → 가장 좋음
  - **[시즌]** 특정 달에 몰림 → 그 달 두 달 전쯤 써 두면 매년 다시 들어옴
  - 올해 검색이 작년 절반도 안 되거나(식는 중), 한 달만 반짝한 키워드는 뺍니다.
- 씨앗 키워드는 `config.toml`에 `[evergreen]` 아래 `seeds = { "생활정보" = ["...", "..."] }` 처럼 바꿀 수 있습니다.

검색 흐름은 **네이버 데이터랩(검색어트렌드) API**로 봅니다. 2026년부터 이 API는 NAVER API HUB로 옮겨졌습니다.
화면에 "데이터랩을 쓸 수 없어서"가 나오면 네이버클라우드 콘솔 > NAVER API HUB 에서 블로그 검색을 쓰던 그 앱에
**검색어트렌드(데이터랩)** API를 추가해 주세요. 키는 그대로(search_client_id / search_client_secret) 씁니다.
켜지 않아도 '방법·조건·효능' 같은 말로 짐작해서 [평생?]으로 보여 줍니다.

## 프로그램 창 (0_program_window.bat)
bat 파일을 하나씩 찾지 않고 창 하나에서 다 할 수 있습니다.
- **실행** 탭: 글쓰기·키워드 찾기·로그인 등 버튼 (누르면 검은 창이 새로 떠서 평소처럼 진행)
- **키워드 목록** 탭: keywords.csv 를 표로 보고 키워드·메모·카테고리를 넣고 고치기, 다 쓴 키워드 다시 쓰게 하기
- **글자 색** 탭: 소제목·인용구·핵심 한 줄·도입부·Q&A 색을 색상표에서 골라 저장

## 키워드 자동 채우기
keywords.csv 에 쓸 키워드가 떨어지면, 글쓰기를 시작할 때 프로그램이 알아서 키워드를 골라 넣고 글을 씁니다.
- 평생 키워드 + 지금 뜨는 키워드를 번갈아, S·A 등급이고 이미 쓴 글과 겹치지 않는 것만
- 지금 뜨는 키워드는 연예보다 생활·경제·IT 쪽을 먼저
- **발행은 하지 않아요.** 임시저장까지만 하니 훑어보고 직접 발행하세요.
- 끄려면 config.toml 의 `[autofill]` 에서 `enabled = false`
- 미리 채워 두려면 프로그램 창 → 키워드 찾기 → **키워드 자동 채우기** (13_autofill_keywords.bat)
